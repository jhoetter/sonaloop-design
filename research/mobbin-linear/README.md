# Chart aesthetics research — Linear (via Mobbin)

Reference screenshots for the next wave of `sl-chart` kinds, captured 2026-06-10 from
[Mobbin](https://mobbin.com). The target aesthetic is Linear's: quiet hairline axes, dotted
reference lines, soft band fills, hatched future regions, small stat headers, and per-row
micro-progress indicators — data-dense but never loud. Plane/Jira/Asana screens are included
where they show the same chart kind executed well.
